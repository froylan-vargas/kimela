# Feature create phases for events

## User stories

I want a simple phase creator, a form with server actions if possible, that allows me to create a phase for an event. The form should have the following fields:

Tipo de fase, nombre, y al guardar quede enlazada con un evento.

Una vez creada la fase, se debe poder ver en la ui e implementando drag and drop poder cambiar el order de la fase.

Utilizando el agente frontend y backend, implementa esta funcionalidad.

Frontend debe decidir cual es el mejor lugar para poder ver las fases existentes del evento y poder agregar nuevas fases .
