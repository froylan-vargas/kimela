# auth requirements

Create the plan for authentication.

Consider that there will be 2 types of users:

Type 1: The participant/creator that can create kimelas and subscribe to them.

Type 2: The admin that can create leagues that can be used to create kimelas then, that will update the results of the event sessions, that can create rules for different sports and so on. The admin will be the one that will create the leagues and the kimelas for the different sports.
